# Network-Theory-and-the-Evolution-from-1990s-Drug-Markets
This project uses network theory to compare two real-world drug dealer networks in New York City. The goal is to understand how the structure of illegal distribution networks differs by drug type and how those structures may have unintentionally shaped the trajectory of the opioid epidemic.
